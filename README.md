<h1 align ="center">Linux_Ciberseguranca</h1>
<p>Este módulo faz parte do percurso de Reskilling da Skodji Digital e tem como objetivo capacitar-vos para a segurança prática de sistemas Linux, com uma abordagem orientada a problemas reais de administração e defesa de infraestrutura.</p>

<h1 align = "center" >Conhecimentos, aptidões e competências a desenvolvidos</h1>

<li>OA1 (Analisar) – Avaliar a segurança de redes locais em Linux e mapear portas, serviços e interfaces de rede ativas no sistema.</li>
<li>OA2 (Avaliar) – Auditar de forma profunda os logs de autenticação e os registos globais do sistema operacional para identificar anomalias ou
potenciais vetores de ataque.</li>
<li>OA3 (Aplicar) – Configurar barreiras de proteção perimetral local utilizando firewalls integradas (UFW/Iptables) para controlo restrito de tráfego
de rede.</li>
<li>OA4 (Aplicar) – Implementar políticas avançadas de hardening em serviços de acesso remoto, especificamente no servidor SSH, através de
autenticação criptográfica robusta.</li>
<li>OA5 (Criar) – Desenvolver auditorias automatizadas de conformidade e segurança do sistema utilizando ferramentas especializadas (Lynis) e
produzir relatórios técnicos de mitigação</li>
