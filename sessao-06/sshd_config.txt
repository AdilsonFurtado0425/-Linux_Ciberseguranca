Configurações ativas do SSH (/etc/sshd_config):


 


PermitRootLogin no: Bloqueia o login direto do usuário robot via SSH.
 PubkeyAuthentication yes: Permite a autenticação por chave pública.
 PasswordAuthentication no: Desativa a autenticação por senha comum.
KbdInteractiveAuthentication no: Desativa autenticação interativa por teclado.
UsePAM yes: Utiliza os módulos de autenticação plugáveis (PAM).
 X11Forwarding yes: Permite o redirecionamento de interface gráfica X11.
 PrintMotd no: Desativa a exibição da mensagem do dia (MOTD) ao logar.
ubsystem sftp: Configura o subsistema para transferência segura de arquivos (SFTP).
